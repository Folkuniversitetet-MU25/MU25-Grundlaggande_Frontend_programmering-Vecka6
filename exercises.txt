Självständiga övningar – HOF, destrukturering

Mål:

Träna forEach/map/filter, destrukturering

Instruktion: Jobba i ordning BAS → MEDEL → AVANCERAD

Ha Consolen öppen.

===================================================
BAS
===================================================

1)Delade tal (map)
Skapa const numbers = [2, 5, 8, 10].
Skapa const divided = ... med map. Logga resultatet.

2)Filtrera namn (filter)
const people = ["Al", "Sara", "Omar", "Bo", "Mira", "Mohammad", "Kung Carl Gustav 8"].
Skapa const longOnes = ... som tar bort namn kortare än 4.

3)forEach som logg
Med forEach, logga “Person: NAMN” för varje people.

===================================================
MEDEL
===================================================

4) Destrukturera objekt
const product = { id: 101, title: "Penna", price: 19 }
Plocka ut title och price och logga “Penna – 19 kr”.

5) Destrukturera array
const coords = [12, 45, 30] → plocka x, y, z via destrukturering.

6) Kombinera filter och map: hitta alla jämna tal i [1,2,3,4,5,6] och dubbla dem.

===================================================
AVANCERAD (valfritt för den som blir klar för här kan ämnen vi inte hunnit prata om på lektionen komma behövas för att kunna lösa uppgifterna) 
===================================================,

7) Kedja metoder
const vals = [1,2,3,4,5,6] → ta jämna (filter), dubbla dem (map), summera med reduce (kan ni, annars logga listan).

8) Säker filter

Skriv function safeFilter(arr = [], predicate = () => true) { return arr.filter(predicate); } 

och testa:

safeFilter([1,2,3], n => n>1)

safeFilter() (ska inte krascha).
